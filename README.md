## How It Works

🔄 **Autonomous Research Loop**  
Uses an OODA loop to plan, research, evaluate findings, and adapt its next actions dynamically.

🛡️ **Agent Harness**  
Eight runtime hooks give the agent freedom to make decisions while keeping execution safe and controlled.

🧠 **Persistent Memory**  
PreCompact preserves critical research state across long-running tasks and context compression.

⚡ **Multi-Agent Collaboration**  
An orchestrator coordinates scraper sub-agents to research multiple sources in parallel.

✅ **Continuous Evaluation**  
Fourteen graders—including 10 code-based checks and 4 LLM judges—continuously evaluate research quality.
